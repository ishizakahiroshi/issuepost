## ja

各アプリが受け取った報告を共通の台帳に記録する、開発中の自己ホスト型サービスです。公開リポジトリには Go の HTTP API、保存層、SQL スキーマがあります。ダッシュボードはまだ提供していません。紹介動画は API の仕組みを説明する概念デモです。

## en

A self-hosted service in development for recording reports received by multiple applications in one ledger. The public repository contains a Go HTTP API, a storage layer and a SQL schema. A dashboard is not yet available. The overview video explains the API as a conceptual demonstration.
